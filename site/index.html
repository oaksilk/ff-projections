What the factors mean

Each factor is measured the same way: the model re-runs the player's projection with that one factor reset to a neutral baseline, holding everything else fixed, and the difference (in points for the scoring you picked) is the factor's effect. That makes it a sensitivity, not a cause: the model has interactions, so the effects don't add up to the projection, and two factors can overlap. There are no fixed weights; the model learned from ten seasons of games how much each input matters, and the effect depends on the player. Everything not listed here, mainly the player's own role and production, is the baseline projection itself.
